# Sistem Transaksi Penjualan

Aplikasi transaksi penjualan sederhana yang dibangun menggunakan **CodeIgniter 4**.

## Fitur

- Dashboard
  - Total transaksi
  - Transaksi hari ini
  - Transaksi menggunakan promo
  - Total produk
  - Grafik transaksi 7 hari terakhir
  - Produk terlaris
  - Transaksi terbaru

- Master Barang
  - Tambah data barang
  - Edit data barang
  - Hapus data barang

- Master Promo
  - Tambah data promo
  - Edit data promo
  - Hapus data promo

- Pengaturan Promo
  - Pengaturan periode promo
  - Pengaturan tipe promo
  - Pengaturan nilai promo
  - Pengaturan produk promo
  - Pengaturan minimal quantity

- Transaksi Penjualan
  - Tambah barang ke transaksi
  - Pengaturan quantity
  - Perhitungan subtotal
  - Pemilihan promo
  - Perhitungan discount
  - Perhitungan PPN 11%
  - Perhitungan grand total

- Invoice
  - Detail transaksi
  - Discount
  - PPN
  - Grand total
  - Cetak invoice PDF


## Teknologi

- PHP 8.4
- CodeIgniter 4
- MySQL
- Bootstrap
- jQuery
- Chart.js
- Dompdf
